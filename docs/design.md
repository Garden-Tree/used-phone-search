## 文字・形

- IBM Plex Sans JP（400/700 だけ）・数字は `tabular-nums`
- 角丸 12px（チップは全丸）・カード間 8px・スマホ左右 16px
- 影・グラデーション・絵文字は使わない（アイコンは lucide-react）

## 部品

- 在庫の行（約90px）: 左にランクの四角。右に ①容量・色／価格 ②電池・SIM・利用制限 ③店名／保証タグ（`warrantyShort`・`redRomShort`）。下に「楽天市場でも販売」の帯。Amazon は「価格は M/D HH:mm 時点」
- 主ボタン: 藍・白文字・高さ 48px
- フッター（`SiteFooter.tsx`）: 広告の表示 → このサイトについて → 公式 X・YouTube → ©。公式 URL は `lib/site.ts` の `OFFICIAL_*` だけ

## ページの並び

- 機種ページ: 要約カード（最安・相場・価格帯・CTA）→ 安心ライン → ヒートマップ → 店別 → ランク／電池 → 安い在庫 → 30日の折れ線 → 折りたたみ → 回線・買取 → 関連
- 機種ページの文字: 最安・相場・件数は要約カードに1回だけ。容量は「相場（128GB）」だけ。定義や注記は書かない。値動きは「↘ −2,300円」。表の金額・件数は固定幅の右寄せ
- 価格カードの3行は押すと店へ（`PickSummary`）。在庫は `PickPair`（電池85%・保証1年）→ 条件なしの最安。電池記載なしの同条件は「他N件」（`CheapestRows`）
- iPhone「直す？買い替える？」（`RepairOrReplace.tsx`）: 公式の修理料金（確かめた機種だけ）・相場・1つ上の世代の相場（3件以上）・差額 →「修理で済ませるなら [PR]」
- iPad「選ぶときの目安」（`IpadGuide.tsx`）: Pencil（`lib/ipadPencil.ts`）・容量ごとの件数と最安・Wi-Fi／Cellular
- 検索: h1・件数・最安 → 条件のチップ → 在庫。スマホは下に「絞り込み」「並び替え」固定
- トップ: h1・検索欄 → 人気の機種 → 目的・予算 → 値下がり → シリーズ → 店 → 運営者

## PC（md 以上）

- 最大幅 1360px。globals.css の zoom（1024px〜 1.15・1600px〜 1.3）
- 機種ページ: 左 本文・右 340px の固定サマリー。本文の中は 1360px 以上で2列。下の固定バーは出さない
- 検索: 左 280px に絞り込み。トップ: 人気の機種 3〜4列・店 4列
