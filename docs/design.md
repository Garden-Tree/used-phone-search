## 部品

- **在庫の行**（全ページ共通・1件約90px）: 左にランクの四角（30px）。右に3行
  1. 容量・色 ／ 価格（赤・太字・右寄せ）
  2. 「電池 90%」（緑青）・SIM・利用制限
  3. 店名 ／ 保証の短いタグ（例「保証3ヶ月・赤ロム永久」）
  - 下に「楽天市場でも販売（ポイント付き） 45,800円 ›」の帯（あるときだけ）。Amazon は「価格は M/D HH:mm 時点」
- **保証の短いタグ**は `lib/shops.ts` の `warrantyShort`・`redRomShort`（長文の `warranty`・`redRom` は詳細表示用に残す）
- 主ボタン: 藍 `#4338CA`・白文字・高さ 48px

## ページの並び

- **機種ページ**: パンくず → h1 → 更新日時・店数・運営者・PR → 同シリーズの機種チップ → 最安値／相場／在庫 → 結論の1文（「ランクB以上・バッテリー85%以上なら ○円〜」）→「安い順に在庫を見る」→ 検品担当のひとこと → 容量×ランク（ランクの意味は目安として「美品・小傷あり・目立つ傷」）→ 安い在庫5件（「すべて見る」）→ 最安値の推移 → 検品担当が見るポイント → 折りたたみ（バッテリー別・ランク別・ショップ別の最安値と保証・スペック・アップデート保証・特徴・データの集め方）→ 比較・関連機種。スマホは画面下に「機種名 最安〜｜在庫を見る」を固定
- **検索**: h1・件数・最安 → 適用中の条件のチップ（×で外す）→ 在庫の行。スマホは画面下に「絞り込み（n）」「並び替え」を固定、絞り込みは下から出る画面
- **トップ**: h1・説明・検索欄 → 人気の機種（2列）→ 目的・予算 → 値下がり → シリーズ → 比較している店（2列）→ 運営者

## PC（md 以上）

- 中身の最大幅 1120px。ヘッダーは同じ
- 機種ページ: 2列（左 本文、右 340px の固定サマリー: 最安値・相場・在庫・結論・「在庫を見る」）。画面下の固定バーは出さない
- 検索: 左 280px に絞り込みを常に表示、右に在庫の行。画面下の固定バーは出さない

## 変えないもの

- `metadata`（title・description・canonical・OGP）・JSON-LD・`verification.google`・GA（`data-shop-click` などの `data-*`、`ShopClickTracker`）・アフィリエイトの付け方（`lib/affiliate.ts`）・`rel="sponsored"`
- 検品担当の文面（`InspectionTips`）・保証の文面・「公式で確かめた値だけ載せる」方針。製品画像は載せない
