## ページの並び

- **機種ページ（10/16〜の決定版 A+B。下の古い並びは置き換え済み。新しい並びは ideas/2026-10-16.md）**: 要約カード（最安・相場・価格帯バー・数字タイル・CTA）→ 安心ライン → ヒートマップ → 店別の横棒 → ランク／バッテリーの積み上げ棒 → 安い在庫5件 → 30日の折れ線 → 折りたたみ → 回線・買取タイル → 関連。旧: パンくず → h1 → 更新日時・店数・運営者・PR → 同シリーズの機種チップ → 最安値／相場／在庫 → 結論の1文（「ランクB以上・バッテリー85%以上なら ○円〜」）→「安い順に在庫を見る」→ 検品担当のひとこと → 容量×ランク（ランクの意味は目安として「美品・小傷あり・目立つ傷」）→ 安い在庫5件（「すべて見る」）→ 最安値の推移 → 検品担当が見るポイント → 折りたたみ（バッテリー別・ランク別・ショップ別の最安値と保証・スペック・アップデート保証・特徴・データの集め方）→ 比較・関連機種。スマホは画面下に「機種名 最安〜｜在庫を見る」を固定
- **iPhone の「修理するか、中古に買い替えるか」（10/21〜）**: 折りたたみの後・PR タイルの前の白いカード（広告ではない）。Apple 公式の電池交換・画面修理（保証対象外・税込・確認日と出典リンク）と中古の相場・最安値を並べるだけ。公式で確かめた機種だけ（`lib/appleRepairPrices.ts`・`RepairOrReplace.tsx`）
- **iPad の「選ぶときの目安」（10/21〜）**: 同じ位置の白いカード。使える Apple Pencil（公式の互換性ページで確かめた機種だけ・`lib/ipadPencil.ts`）・在庫のある容量の件数と最安・Wi-Fi／Cellular の1行説明（`IpadGuide.tsx`）
