## 3. 構成（伸びている動画に共通すること）

1. **最初の15秒に「誰の・どんな困りごとか」**: タコは家族（お父さんの13・祖母の SE 3）の困りごと3つから入る。おくつは肩書き（元店員）と「最後まで見ると〜が分かる」。うちは「結論から」で始まり、問いを持つ人がいなかった → **ずんだもんの困りごとから入る**（SE 3 の回〜）
2. **先に答えを、困りごとごとに分けて言う**: 「電池だけなら交換／容量なら17e／0.5倍なら17」
3. **全体の地図を最初に見せ、途中で振り返る**: 空の ○△ の表を章ごとに埋める・章の目次タブ・1枚の年表に線を引く
4. **最後に決める場面（物語の決着）**: 最初の困りごとの人が「◯◯にする」と決めて終わる → **最後にずんだもんが決める**（SE 3 の回〜）
5. **用語を「何ができるか」で言う**: 「0.5倍で広く撮る超広角」「顔で開く Face ID」「下から上へなぞって途中で止める」
6. 長さは 9:40〜14:46（みずおじさんは30分）。うちの8〜9分は短すぎない
7. 説明欄の1行目が「答え：…なら〜、…なら〜」。説明欄だけで答えが分かる

## 4. 画面

- **1画面の情報が少ない**: タコは「見出し1行＋絵1枚＋1〜2行」。要素は3〜6個。文字は大きい（見出しで画面の高さの約6%、字幕で約4%）
- **声より先に画面**: 言った要素がその場で出る。うちは図が空のまま数字を言っていた所があった（13 の回の 2:00・7:00）
- **絵が中身を語る**: タコは統一タッチのイラスト、おくつ・みずおじさんは実機や端末の画像が常に映る。うちは表と数字だけだった → **写真（CC）・いらすとや・グラフ**を増やした
- 同じ数字を字幕・見出し・カードで3回出さない
- キャラは画面の下の角に小さく、字幕はその間（タコもうちの d2 と同じ形）

## 5. 動き・テンポ

- タコ（SE 3）は1分で切り替え約12回（**約5秒に1回なにかが変わる**）、おくつは約7回。うちの 13 の回は6回、最初の30秒は1回だけだった
- 変化の付け方: 画面の切り替え・表の行が埋まる・棒が伸びる・1枚の図にカメラが寄る（タコの年表）
- **11/27 追加（4本を2〜3秒ごとに見た・ideas/2026-11-27.md）**: タコ 40万回の回は最初の1分で約20回＋カメラが常に動く（3秒に1回）。ずんだもん解説（25万）は約18回で、表情・ポーズを1台詞ごとに替える。強調は字幕の色でなく、数字の札と表で出す
- みずおじさんは60秒同じスライドのこともあるが、登録71万・本人の声・実機写真という別の強みがあるので参考にしない

## 6. サムネ

- タコ: 白地に極太「iPhone 13、まだ使える？」（画面の高さの約45%）＋下に**2択の値段カード2枚**（電池交換 1万5600円／17e 12万4800円）＋考え込むキャラ。年の回は暗い地に答えの「2033年」を光らせる
- おくつ: 黒地に帯3段（「型落ちiPhone」「やめとけ5台」「正解3台」）、文字が画面の約7割、× と ✓
- みずおじさん: 自分で撮った実機の写真＋集中線＋「今買うならコレ！」
- うちの 13 の回は「電池1.6万円」だけで替える側の値段がなく、文字が小さく余白が大きかった → 案は **2択の値段を左右に**（SE 3 の回は 13 と同じ形 thumb-S1 にした。2択の型は未作成・スキル youtube-thumbnail）

## 7. 声

- タコ・うち: 合成音声の二人の掛け合い。差は、タコが毎回3人目（お父さん・祖母）を出していること
- おくつ・みずおじさん: 本人の肉声
