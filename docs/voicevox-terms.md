# VOICEVOX のキャラクターの規約

VOICEVOX はキャラクター（話者）ごとに利用規約が別にある。**話者を変えるときは、そのキャラクターの規約を読んでから使う。** 規約は予告なく変わるので、毎月1日の見直しで開き直す。

- **クレジット**: 声を使った動画は、説明文に「VOICEVOX:キャラクター名」を入れる（ショートは `youtube.txt` に自動で入る。横動画も説明欄に書く）
- 春日部つむぎ: 公式の規約（https://tsumugi-official.studio.site/rule ・10/21 確認）で、商用・非商用ともに利用可。条件はクレジット「VOICEVOX:春日部つむぎ」を動画内か概要欄などに書くこと。禁止は誹謗中傷・第三者に不快感や権利侵害・特定の思想や団体に関わるもの・二次配布など
- ずんだもん: 規約（https://zunko.jp/con_ongen_kiyaku.html ・10/22 確認）で商用・非商用ともに利用可。条件はクレジット「VOICEVOX:ずんだもん」を説明欄など見れば分かる所に書くこと。禁止は公序良俗に反する利用・政治や宗教・特定の個人や団体の非難や応援・情報商材とその宣伝・意図的な虚偽や誤解を招く内容など
- 青山龍星: 規約（https://www.virvoxproject.com/voicevoxの利用規約 ・10/21 確認）で、個人はクレジット「VOICEVOX:青山龍星」を書けば商用利用できる。**法人が関わる利用は、事前に ななはぴ への確認が要る**

どのテーマ・動画でどの声を使うかは、スキル youtube-shorts・longform-video と `shorts/make-short.tsx` の `THEME_SPEAKER`。
