# Google の表示が減った理由（11/21 夜・ユーザー「表示回数減ってる理由を調査して。打つ手は？」）

出どころ: GSC API（dataState=all）。比べたのは 10/18〜24 と 11/14〜20 の各7日。スクリプトは scratchpad の gscdrop1121.mjs・gscq1121.mjs

## 数字
- 表示 3,041 → 675（−2,366）。うち **18 Pro・18 Pro Max・17 Pro の3ページで −1,053**、問いでは「iphone18 pro max 中古 最安値」457→1・「iphone18 pro 中古 最安値」284→1・「iphone17 pro 中古 最安値」139→0
- 「18」を含む問いは **9割がパソコン**（例 10/18 パソコン 236・スマホ 1）、クリックは 493表示で1回。**11/3 にぱったり止まった**（コア更新 11/10 より前）
- 「18」を含まない問い: スマホ 40〜60/日（11/5〜12）→ **11/14 から 12〜19/日**。平均順位 11〜13 → 20〜28。落ち始めは 11/13 で、コア更新（11/10〜）と重なる
- 種類別（前→後）: iphone 1,308→186・budget 512→121・compare 348→155（ページ数は 49→65 に増えた）・galaxy 264→26・aquos 141→30・ipad 125→37
- 順位帯: 4〜10位の表示 835→60。21位以下は 85→93

## 読み
1. **いちばん大きな減り（18 Pro 系）は、ほぼ人ではない**。パソコンからだけ・クリックなし・同じ言い回しの問いが毎日・11/3 に一斉に止まった → 順位を毎日調べるツール（競合や業者の順位チェック）の表示と考えるのが自然。止まっても売上・訪問は変わらない（この問いからのクリックは28日で1〜2回）
2. **本当の減りは、人の検索（スマホ）の 1日 45→15 ほど**。原因はコア更新で順位が 12位前後→20位台に下がったこと。とくに予算別・Galaxy・AQUOS の機種ページ。比較ページは減りが小さい（違いの表という独自の中身があるため、と読める）
3. 訪問への影響は小さい: Google からのセッションは 10月下旬でも 1日 5〜13。いま訪問の6割は ChatGPT

## 打つ手
- **今はページを動かさない**（台帳どおり）。コア更新の完了の発表を待ち、11/24〜25 に種類別で見直す。更新の最中に動かすと、何が効いたか分からない
- 完了の後に考える候補（どれも本番の変更なので案を見せてから）:
  1. **中身の薄いページを noindex にする**: 在庫が少ない機種ページ・予算別・検索。Google はひな形で大量に作ったページを下げる。513 ページを出しているので、在庫の少ないページが全体の評価を下げている可能性
  2. **機種ページの冒頭に、ここにしかない数字を足す**: 比較ページが落ちにくかったことから。容量ごとの相場と件数（打ち手3。15 Pro で準備済み）・電池別・ランク別の差など
  3. 比較ページを足す（11/30 の判定の後）
- 18 Pro 系の表示は追わない（人ではないため）
