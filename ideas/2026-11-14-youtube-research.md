# YouTube を伸ばすための調査と分析（11/14 夜）

ユーザー「現在のサムネとか原稿を、どのように修正したらいいかを調べて。公式・非公式問わず」。作業役4つ（公式・非公式・うちの現状の点検・競合）が集め、分析は Fable。
数字の出どころ: YouTube Studio（ideas/2026-11-14.md の夜の節）。点検の画像は scratchpad（消える）。

## いまの数字の読み方（公式の定義から）

- ショートの「約1,000回」は 2025/3/31 から「再生が始まった回数」（スワイプされた分も入る）。実際に見た数（エンゲージ ビュー）は 1,000 × 視聴を継続 21〜55% ＝ 約210〜550回。比べるのは「視聴を継続」とエンゲージ ビュー
- 新しいチャンネルのショートの中央値は30日で約1,360回（vidIQ・44.8万ch）。1,000回は「止められている」のではなく普通の値。伸びるのは10本に1〜2本
- 配信を決めるのは「見るかスワイプするか」（公式発言）。本数・時刻・ハッシュタグ・サムネではない。消して上げ直すのはスパム扱いのおそれ
- 視聴を継続の公式のしきい値はない。非公式（Galloway・2023）では 60% 未満はほぼ伸びず、伸びた回は 70〜90%。うちの最高は 54.5%
- 長い動画の CTR は公式に「半分のチャンネルが 2〜10%」。1.6% は下。ただし関連動画の広い試し出しでは低く出る
- ショートを見た履歴は長い動画のおすすめに使われない（公式発言・2022）。登録は長い動画で決まる（非公式）。+4人／1.4万回は 0.03% だが、エンゲージ ビューで割れば 0.06〜0.13%

## 分析1: ショートは「0秒目に題材が読めるか」で分かれている

| | 高い回（在庫ランキング・45〜55%） | 低い回（1世代前・21〜24%） |
| --- | --- | --- |
| 0秒目の文字 | 「中古で／いちばん多いAndroidは」＋棒の中に「？？？」＋838件 | 「差は／34,400円」だけ |
| 題材が画面で分かるか | 分かる | 分からない（機種名も「1世代前」も無い。声で分かるのは約4秒後） |
| 答え | 伏せている | 1位の答えの金額を最初に出している |
| 図 | 横棒1本 | ラベルのない四角2つ |
| 背景 | 暗い | 明るい・端末の実写と図が重なる |

- 低い回は「何の話か分からない＋答えはもう出ている」。見続ける理由が0秒目に無い
- 声（ずんだもん）は高低の両方にいるので、声では分かれていない。題も10本とも1位入りで差なし
- 例外: 在庫型の iPhone（SE 第3世代）は 29.3%。同じ型なのに低い。0秒目の画面は未確認（背景か、「iPhone」が広すぎるか）。次に見る
- 型そのものの差（在庫数のほうが面白い）と0秒目の差は、いまのデータでは分けられない → 1世代前型の0秒目だけ直して5本で比べる
- 「問いの形は弱い」（vidIQ・長い動画の題・0.82倍）は、うちの実測（問い＋答えを伏せた回が勝っている）と合わない。自分の数字を優先
- 検索の棚で再生が多いショート（8万〜20万）は、1コマ目が「人が実機を持つ実写＋太い字幕1〜2行」。11/16 からの実写／AI の0秒目の比較はそのまま続ける

### 直し方（1世代前型・電池型のつかみ）

1. 0秒目に題材の言葉を出す: 「iPhone／1世代前にすると」のように、何の比較かを2行で
2. 答えを伏せる: 金額は「？？？円安い」。数字は出すなら答えでないもの（例: 比べた組の数）
3. 四角2つに機種名のラベル（「16 Pro」「15 Pro」）。ラベルのない図は置かない
4. 背景は暗くする（文字と図が実写に重なっても読める）
5. つかみの声は3秒以内（在庫型 2.6〜3.5秒・低い型 3.7〜4.5秒）

判定: 直した回5本の「視聴を継続」が 21〜24% → 40% 以上なら採用。あわせて在庫型の比率を上げる

## 分析2: 長い動画は「サムネのいちばん大きい文字」が違う

| | CTR 4〜5%台（地雷・Pixel・Watch） | iPhone 13（1.6%） |
| --- | --- | --- |
| いちばん大きい文字 | 主張か数字（地雷6台／4倍損／3.8万円） | 問い「今買い？」（シリーズ名） |
| その回だけの発見 | 大きく出ている | いちばん小さい札（相場 5.1万円） |
| 地の色 | 暗い（紺・黒・暗赤）＋白・黄・赤 | 明るい緑（16 オレンジ・12 青） |
| 題の長さ | 34・42字（Watch は79字） | 53字 |

- 平均視聴は 3:05（34.5%）で過去の回より長い → 中身ではなく入口の問題
- 13・16・12 の台本には、それぞれ意外な発見がある（13: 電池85%以上は1割だけ／16: 新品との差は1.9万円・未使用品は新品より高い／12: 画面修理が本体より高い）。サムネではそれが「今買い？」の下に埋もれている
- 関連動画の枠で並ぶ相手は、みずおじさん・最新テック・デイリーフォース・まさもば（数万〜数十万回）。主文句は6〜10字で主張が1〜2個（「今買うならコレ」「絶対に買うな」「やめとけ5台 正解3台」）。赤・黄の太い文字が6〜7割、端末の実写が9割
- 11/13 に決めた型1（機種名／今買い？／数字の札）を変える提案になる → ユーザーの確認が要る

### 直し方（サムネ）

1. いちばん大きい文字を「その回だけの発見」にする。「今買い？」は小さくするか題に任せる
   - 13: 「買っていい」＋「電池85%は1割だけ」／または「5.1万円」を最大に
   - 16: 「新品と1.9万円差」を最大に／または「未使用品は新品より高い」
   - 12: 「画面修理 4.6万円」＋「本体より高い」／または「64GBは選ぶな」
2. 地を暗くして、文字は白・黄・赤（4〜5%台の3本と同じ）。実機の写真はそのまま
3. 要素は3つまで・104px 以上・端から 60px（今の決まりのまま）

### 直し方（題）

- 頭に発見を置き、40字前後に: 例「中古iPhone 16、新品との差は1.9万円だけ｜それでも中古にするならこの1台【2026年11月】」
- 題の A/B テストは公式にあるが（2025/12〜）、表示が足りないので使わない（11/13 の判断のまま）。差し替えて前後で見る

### 直し方（原稿の冒頭）

- 6本とも「結論から。」で始まり、答えは0秒で出ている → ここは良い
- 登録のお願いが 25〜45秒（離脱がいちばん多い最初の1分の中）→ まとめの前へ移す
- 2章目の「数字の出どころ」（28〜61秒）が毎回同じ場所 → 冒頭は画面の1行（16店・◯件・◯月◯日）にして、説明は後ろか説明欄へ。収益化の審査で「自社集計」が見える利点は画面の1行で残る
- 13 は金額が声に出るのが 21.5秒（他は4〜17秒）→ 最初の10秒に金額を入れる
- 優先度は入口（サムネ）より下。いまの律速は CTR

## 分析3: ネタは「買う人」より「持っている人」のほうが広い

- 「iPhone 13、まだ使える？電池交換と17eの2年総額で…」（登録1,060人のチャンネル・36.7万回・AI のキャラ2人の掛け合い）。同じチャンネルの他の回は 900〜4,100回なので運の面もあるが、検索の上位には「いつまで使える」「まだ使える」「買い替え不要」が並ぶ
- 「中古の13を買う人」より「13を持っている人」のほうがずっと多い。うちの「今買い？」は買う人だけに向いている
- サイトには持っている人向けのページと収益の枠がある（/how-long・/iphone/battery・「直す？買い替える？」・買取）→ 次の機種の回は「iPhone ◯◯、まだ使う？電池交換◯円か、売って中古の◯◯か」を足す（題・構成はうちの数字で作る。他人の題は写さない）
- 冒頭の入り方も参考: 身近な人の困りごと → 15秒で答えと金額

## そのほか

- 収益化の審査（量産型のコンテンツ）: 毎日の型どおりのショートは「数字だけ差し替え」に見えると不利。回ごとのひと言（検品担当）と、画面・説明欄の「自社集計・店数・日付」を続ける。合成音声そのものを不可とする公式の記述はない
- ショート→長い動画: 公式の推奨は「関連動画のリンク・最後の5秒に声と画面で誘導・長い動画の冒頭ですぐ答える」。いまの作りと同じ
- 見つけた不具合: `longform/2026-11-11-apple-watch/youtube.txt` の1段目が壊れている（youtube-final.txt は正しい。公開中の説明欄がどちらかは未確認）。SKILL.md 242行「画像・製品写真は使わず」は今の実写の0秒目と食い違い

### 実験1: 横動画のサムネを「暗い地＋その回の発見が最大」に

- 何を変えたか: 11/13 に決めた型1（機種名／今買い？（最大）／数字の札・明るい地）→ 型R（機種名／その回の発見（最大・黄）／札・暗い地）。写真・文字の大きさ・余白の決まりは同じ。スクリプト `longform/thumb-v14-finding.tsx`・一覧 `longform/thumb-v14-contact.png`
- 13 の回（RZDic1sW4p0・公開中）: thumb-Q1 → **thumb-R2**（「iPhone 13／5.1万円／まだ買っていい」）
- 16 の回（YSnBsKwo_2c・11/15 12:00 公開）: thumb-Q1 → **thumb-R1**（「iPhone 16／新品と／1.9万円差」）。公開前なので Q1 の数字はない
- 選ばなかった案: 13-R1「買っていい＋電池85%以上は1割」（168x94 で札が潰れ気味）・16-R2「未使用品は新品より高い」（台本は「高いことがある」で、言い切りが強い）
- 仮説: CTR 4〜5%台の3本（地雷・Pixel・Watch）は「暗い地＋主張か数字が最大」、1.6% の 13 は「明るい地＋問いが最大」。関連動画の枠の相手（みずおじさん・最新テック等）も主張が最大
- **判定 11/22**（差し替えから7日）: Studio の流入元「関連動画」の CTR
  - 13: Q1 の期間（11/13 12:00〜11/14 夜: 表示 3,341・CTR 1.6%・関連 1.5%）と R2 の期間（11/15〜11/21）を比べる
  - 16: 公開から7日の関連 CTR を、13 の Q1（1.5%）と比べる
  - 両方 3% 以上 → 型R を機種ごとの回の型にする（12 の回 11/21 公開も型R で作り直す）。片方だけ・どちらも 2% 未満 → 型1 との違いをもう一度考える。表示 1,000 未満なら判定を1週のばす
  - 注意: 公開直後と数日後では出る枠が変わるので、同じ期間の長さ・同じ流入元どうしで比べる。1本ずつなので偶然の差もありうる
