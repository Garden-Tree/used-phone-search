## 夕方: ChatGPT に引用される方法（調査だけ・サイトは変えていない）

### 本番の現状（curl・11/12）
- robots.txt は `User-Agent: * / Allow: /` だけ＝OAI-SearchBot・ChatGPT-User・GPTBot・PerplexityBot・ClaudeBot・Google-Extended すべて許可。各 UA で /ipad/ipad-air-5th-gen は 200。ただし前段は Cloudflare（`Server: cloudflare`）で、Cloudflare の AI ボット判定は IP で行うため、UA を名乗った curl の 200 は「弾いていない」の証明にならない
- /llms.txt・/llms-full.txt・/.well-known/llms.txt はどれも 404
- sitemap 407 URL。lastmod は 404 件がその日の書き出し時刻（全件同じ）・2件が 11/1
- 構造化データ: 機種ページ＝BreadcrumbList・Product（UsedCondition・AggregateOffer lowPrice/highPrice/offerCount・JPY）・FAQPage（5〜7問）・WebPage（description＝冒頭の文・dateModified）。予算別・/iphone＝BreadcrumbList・WebPage（dateModified あり）。**比較ページ＝BreadcrumbList・FAQPage だけ（WebPage・dateModified なし）**
- 冒頭: 機種ページは h1 の直後に「2026/11/12時点、iPad Air (第5世代)の中古の相場は64GBが71,280円、256GBが85,980円（最安56,980円・64GB）。大手中古ショップ10店の290件を集計」＝答えの形になっている（11/10 の変更）。比較は h1 → 違いの表 →「2026/11/12 時点、中古の最安値は…」。予算別も日付つきの1文から
- 気づき: 比較の meta description は「大手中古ショップ16社」、本文は機種ごとに「13店・11店」。数え方が2つある（機種ページの description は在庫のある店の数）
- HTML は機種ページ約34万字・h1 は2.4万字目（前はヘッダー・ナビ）。読む側で問題になる根拠は見つからなかった

### 外部の知見（根拠の強さ）
- 【公式・OpenAI】ChatGPT 検索に出るには OAI-SearchBot を拒否しないこと。ChatGPT-User はユーザーの操作でページを開くときの取得で、検索に出るかは決めない。GPTBot は学習用で検索とは別。robots の反映は約24時間。sitemap・IndexNow・Bing・llms.txt への言及はない（developers.openai.com/api/docs/bots・help.openai.com の publishers FAQ）。参照元に utm_source=chatgpt.com が付く
- 【公式・Bing】AI 回答への採用は保証しない。見出し・表・FAQ・データと出典・正確な lastmod と IndexNow を勧める。AI Performance（2026/2〜）は Copilot と Bing の AI 要約の引用で、ChatGPT は含まない（blogs.bing.com 2026/2）
- 【提案・llmstxt.org】llms.txt は「標準化の提案」。主要 AI が使うとは書いていない
- 【計測・第三者】llms.txt: Ahrefs（2026/6・13.7万ドメイン）有効なファイルの97%は5月に1回も取られていない。取りに来たうち AI の検索系は約1%。EZY（83サイト・12週）OpenAI のクローラーは robots.txt 3,990回に対し llms.txt 7回。引用が増えたという結果は見つからない
- 【計測・第三者】ChatGPT と Bing: Seer（2025/2・約500件）引用の87%が Bing 上位と一致 → Ahrefs（2026）URL の一致は約10%・Profound（2025）Bing 26%→8%・Google 12%→33%。「Bing だけ見ればいい」は弱くなった
- 【計測・ベンダー】AirOps: JSON-LD のあるページは引用率 38.5% vs 32.0%。ChatGPT は1問で平均2つの派生クエリを作り各約10件を読み、読んだうち引用は約15%。Profound: 引用の44%はページの最初の1/3から（又聞き）。どれも GEO ツールの会社の数字
- 【うちのデータ】ChatGPT 経由の上位の入口は Google の表示がほぼ0（iPad 第9世代: ChatGPT 35〜36セッション/週、GSC 表示 0〜1/週）。うちは Google の順位で ChatGPT に拾われているわけではない
