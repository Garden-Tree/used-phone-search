# YouTube ショート（中古スマホ相場）の構成案（10/17）

## 調べたこと

- **S&P500最強伝説**（登録33.6万・484本）
  - 本チャンネルは長尺のみで、ショートはない。サブチャンネル（9.6万）がある。
  - 毎週土曜19時の定期投稿。テーマは1つ（S&P500）に絞っている。
  - 顔出しなし。キャラクターのアバターと、大きな文字のサムネで統一。
  - タイトルは感情＋結論型。例「儲かる5年目、いよいよ始まる！【S&P500, NASDAQ100】」（6日で33万回）。
- **中古スマホ相場の動画**: 国内で、相場データを定期的に出しているチャンネルは見つからなかった。相場サイト（aucfan・kashi-mo など）は文字が中心。
- **収益化ポリシー**（2025/7/15〜）
  - 「大量生産・繰り返しの多いコンテンツ」を明確に対象外にした。テンプレートで作った、動画どうしの違いが小さい動画が含まれる。
  - AI の利用自体は可。ただし、人の判断・経験が入っていることが条件。
  - 実例: 「ゆっくり不動産」（71万）は「コンテンツの繰り返し」で一度停止し、後に再開された。
- **ショートの長さ**
  - 解説系は 35〜45 秒が目安（二次情報）。
  - 最初の 2〜3 秒で結論か数字を見せる。
- **リンク**: ショートの説明欄・コメントのリンクは 2023/8 からクリックできない。サイトへはチャンネルのプロフィールのリンクから誘導する。
- **作り方の事例**: Remotion（React で動画を作る仕組み）にデータを渡し、1つの型から1本ずつ書き出す例が多い。

## 方針

- 型（見た目・長さ）は統一する。毎週テーマを変えて、動画どうしの違いを大きくする。
- 毎回、検品担当のひと言（実体験・判断）を入れる。これが「本物」の部分。
- 毎週1本、決まった曜日に出す。同じ動画を X にも投稿する。

## 1本の構成（縦 1080x1920・約40秒）

| 秒 | 場面 | 中身（例） |
| --- | --- | --- |
| 0–3 | つかみ | 大きな数字。「iPhone 15、1週間で −4,000円」 |
| 3–12 | ランキング | 棒が伸びる TOP3〜5（値下がり幅・相場の安さ） |
| 12–22 | 推移 | 1位の機種の30日の相場グラフ（線が描かれる） |
| 22–34 | ひと言 | 検品担当の判断。「この値段なら 85% 以上を選んで」 |
| 34–40 | 締め | 「全機種の相場はプロフィールのリンクから」・日付・16店のデータ |

## 週替わりのテーマ（4週で一巡）

1. 今週いちばん値下がりした中古 iPhone（PriceSnapshot の週差）
2. ○万円で買えるいちばん新しい iPhone（予算ページの数字）
3. 2機種比較（例: 15 vs 16。比較ページの数字）
4. 検品担当の豆知識（バッテリー表記の違い・ランクの見方。数字は少なめ）

## 仕組み

1. `npm run short -- <テーマ>`
   - DB の集計（既存の getModelMarket・snapshot）から、台本 JSON（場面・字幕・数字）を作る。
   - ここで私が台本を書き、ユーザーが確認する。
2. 場面の画像を next/og（X の画像と同じ仕組み）で 1080x1920 で描く。
   - 棒・線の動きは、コマごとに描いて重ねる。
3. ffmpeg で、場面・切り替え・字幕・BGM・声を1本の mp4 にまとめる。
4. ユーザーがアップロードする（YouTube API の自動投稿はしない）。

- 声: ユーザーの録音（ひと言の部分だけ）。録れない週は字幕と BGM だけにする。
- BGM: YouTube オーディオライブラリの曲（ユーザーが選んでダウンロード）。
- Remotion は動きの自由度が高い。ただしブラウザでの描画が要り、重い。まずは next/og と ffmpeg で作る（追加の部品なし）。

## 判定

- 8週（2か月）続けたら判断する。
  - 1本の平均再生と登録者数を見る。
  - GA で youtube.com からの流入を見る。
