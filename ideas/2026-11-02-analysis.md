## 2. 読み

1. **伸びているのは ChatGPT と X で、どちらも「買う直前の人」**。Google と YouTube は量はあっても買う人を連れてこない。
2. **収益の天井は「クリックの質」**。1週 196クリックのうち価値の高い A8 が 29。楽天は上限1,000円なので、いくら増えても1週 2,000円が上限。にこスマ（＋Yahoo! の VC）のクリックを増やすことが、訪問を増やすより先。
3. クリックの 2/3 が起きる **/search に、にこスマが出る枠がない**。機種ページの3行（11/1）だけでは届かない。
4. Google は **比較ページが入口（38%・CTR 6〜11%）**なのに表示が少ない（各50前後）。18 Pro 系の 2,600表示は順位9〜10・買う人でもない（新品を買う人の下調べ）。
5. YouTube は **型を絞れば継続率が上がる**（在庫・電池 ≫ 予算別）が、サイトには来ない。本数（1日1本→2本）が 48時間の再生を直接決める。
6. X は **返信に寄せるほど表示が伸びる**。自分の投稿は速報より「見ること」「いまいくら」の型。
