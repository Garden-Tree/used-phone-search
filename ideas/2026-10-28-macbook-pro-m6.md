# 新型 MacBook Pro 14インチ（M6）のまとめ（10/28 1時台・動画と X 用）

## 公式で確かめたこと（Apple Newsroom 日本・米国・Apple Store 日本の購入ページ。10/28 確認）
- 発表 2026/10/27（米国時間）。**14インチだけ**。M6 Pro・M6 Max は出ていない（発表に記載なし）。同じ日に M6 の iMac
- 価格: **339,800円（税込）から**（学生・教職員 322,800円）。米国 $1,999
- 予約: Newsroom（日本）は「10月29日（木）より」、購入ページは「10月29日午前2時10分から」→ 動画では「10月29日から予約」とだけ言う。**発売 11月6日（金）**
- 構成（購入ページ）: M6 は 12コアCPU・12コアGPU、メモリ 16GB／24GB／32GB、**SSD は 1TB**。色 スペースブラック・シルバー。Nano-texture ディスプレイを選べる
- M5 比（Apple の比較条件: M5 10コアCPU/GPU・32GB・4TB）: グラフィックス最大30%・AI（LLM のプロンプト処理）最大25%・Neural Engine 最大1.9倍。アプリでは Blender・Xcode 1.3倍
- 電池 最大24時間（Mac で最長）。Wi-Fi 7・Bluetooth 6。外部ディスプレイ2台。端子は HDMI・MagSafe 3・Thunderbolt 4 ×3・SDXC・ヘッドホン。macOS 27 Golden Gate
- デザインは前の M5 から変わらない（発表で変更の記載なし）
- **Apple Store 日本から M5（無印）の 14インチが消えた**。残りは 14インチ M6・14インチ M5 Pro/Max・16インチ M5 Pro/Max
- 前のモデル: 14インチ M5 は 2025/10/15 発表・**248,800円（税込）から**・10コアCPU/GPU（Newsroom 日本）。基本構成の SSD は発表に書かれていない
- 出典: https://www.apple.com/jp/newsroom/2026/10/apple-introduces-the-new-14-inch-macbook-pro-with-m6/ ・ https://www.apple.com/newsroom/2026/10/apple-introduces-the-new-14-inch-macbook-pro-with-m6/ ・ https://www.apple.com/jp/shop/buy-mac/macbook-pro ・ https://www.apple.com/jp/newsroom/2025/10/apple-unveils-new-14-inch-macbook-pro-powered-by-the-m5-chip/
- 参考（二次情報・動画では言い切らない）: M5 Pro/Max は 2026/3 に値上げ（14インチ M5 Pro 369,800円〜。gizmodo.jp）。噂では M7 で新デザイン（gori.me）。OLED・タッチの MacBook Pro は今回は出ていない（MacRumors が 10/8 に予想していた）

## 動画・投稿の切り口（案）
1. **ショート「新型MacBook Pro M6は33.98万円。中古のM5・M4ならいくら安い？」**（1TB・16GB どうし。−5.3万・−8.0万）。macgen（1世代前）の型が使える
2. **「M5（無印）は公式で買えなくなった」**: 14インチの無印は M6 だけに。M5 を選ぶなら中古（55件）
3. **入門は M6 から始まる価格が 33.98万円**: M5 の発売時 24.88万円から +9.1万円（ただし標準の SSD が 1TB。M5 の基本構成の SSD は公式の発表に書かれていないので「容量が違う」とだけ言う）。安く Pro を買うなら中古の M3（16.6万円）・M1 Pro（15.3万円）
4. X: 発表の翌朝に「M6 と中古 M5／M4 の差」の表（1TB・16GB）
