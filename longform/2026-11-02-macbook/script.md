# 横動画 台本（第1稿）: 中古MacBook、いま買うならどれ？

- 数字はすべて 2026/10/27 の集計（`longform/2026-11-02-macbook/data-query.ts` → data-query.log。DB の groupBy・count・aggregate と、中央値の1行だけ。在庫の行は取らない）。**MacBook の在庫がある店は3店**（`activeMacShops`＝イオシス・じゃんぱら・ソフマップ。どれも楽天市場店の在庫）、macOS 27 対応の MacBook の在庫 1,990件（31機種）
- 相場＝在庫がいちばん多い容量（SSD）の中央値（`getModelMarket`。サイトと同じ。容量を添える）。容量ごとの数字は在庫5件以上の容量だけ。メモリは DB の memoryGB（商品名から読んだ値・`parseMacSpec`）
- **予算別の選び方（主観は入れない。台本・説明欄で同じ。ショートの `shorts/themes/macbudget.ts` と同じ考え方）**: `lib/macCatalog.ts` の MAC_MODELS（macOS 27 対応の Apple シリコンの MacBook Air・Pro と MacBook Neo）のうち、在庫30件以上の機種。予算 10万・12万・15万・20万円ごとに、相場が「ひとつ前の予算より上〜予算」に入る機種のうち、相場がいちばん高い機種（同じなら発売の新しい方）。8万円は帯に入る機種がない（いちばん安い Air M1 が 81,980円）ので予算を10万円からにした。iPhone の「予算−1万円より上」は使わない（18万超〜20万円などの帯が空になる）
- 1世代前: `shorts/themes/macgen.ts` と同じ組・同じ容量（両方に在庫5件以上ある SSD のうちいちばん小さい容量）の中央値どうし。メモリをそろえた比べ方（M4→M3 の 16GB どうし・M3→M2・M2→M1 の 8GB どうし）は data-query.log の「メモリ」の中央値から
- スペックは `lib/macCatalog.ts` の MAC_INFO（発売年・画面の呼び名・チップ。Apple 公式の識別ページ・10/15 確認）。MacBook Neo の「A18 Pro・メモリ 8GB・SSD 256GB／512GB・13.0インチ」は同じファイルの頭（apple.com/jp/macbook-neo/specs/・10/15 確認）。A18 Pro が iPhone 16 Pro と同じチップなのは `lib/iphoneSpecs.ts`
- **10/27 に Apple 公式で確かめた値**: 充放電回数の上限の目安 1,000回（Apple シリコンの MacBook Air・Pro と MacBook Neo。「理想的な条件下で実施したテスト結果」）と見方（option キーを押しながら Apple メニュー →「システム情報」→「電源」）＝ https://support.apple.com/ja-jp/102888 。メモリは注文のときに選ぶ構成（MacBook Air M2 の技術仕様「8GBユニファイドメモリ　以下のオプションに変更可能：16GBまたは24GB」＝ https://support.apple.com/ja-jp/111867 ・M5 の仕様も同じ書き方＝ https://www.apple.com/jp/macbook-air/specs/ ）
- **言わないこと**: 性能の体感（速い・重い作業に向く）・ファンの有無・画面や重さの違い（台本では使わない）・「メモリは後から増やせない」（Apple の MacBook のページで確かめられたのは「注文のときに選ぶ構成」まで。後から増やせないと書いてあるのは Mac mini・iMac のページだけ）・新品の値段（`lib/applePrices.ts`・`lib/officialPrices.ts` に Mac がない）・店名を挙げた良し悪し
- 電池85%以上の件数は、電池の最大容量を書いているのが3店のうちじゃんぱらだけ（874／946件。ソフマップ・イオシスの MacBook は0件）なので、「書いてある在庫」と言う。台本では数だけ少し使う
- 長さの目安: 台詞 94行・約3,150字で 約8分40秒（8本目の 3,200字＝8分51秒からの見積もり・速さ 1.15）＋終了画面20秒
- **頭の5秒で結論**。チャンネル登録のお願いは2章の終わり、高評価・コメントは まとめ
- 口調・呼び方は 9本目（`longform/2026-11-01-monthly/script.md`）と同じ。つむぎ＝解説（あーし・ずんだもん先輩）、ずんだもん＝聞き手（僕・〜のだ）
- 掛け合いの軸: 「Pro がいいのだ」「新しいのがいいのだ」と名前で選びたがるずんだもんに、つむぎが「同じメモリ・同じ容量で比べる」を見せる
- この回を作る理由: サイトの MacBook 31機種の毎日の相場（10/15〜）を横動画にまだ使っていない。ショートの macbudget・macgen の長い版
