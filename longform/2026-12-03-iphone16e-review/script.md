## 0:00 結論：1年半使って電池93%。中古の16eは電池90%以上がほとんど

【画面】大きな数字: 1年半で電池 93% / 売った額 68,400円（下取りは 53,000円） / 中古の相場（128GB） 104,280円

つむぎ: 今日は、このチャンネルの運営者が、1年半メインで使ったiPhone 16eの話。
ずんだもん: 1年半使って、どうだったのだ？
つむぎ: 電池の最大容量は93%。売ったら6万8,400円。Appleの下取りより1万5,400円高かったの。
ずんだもん: 今、中古で買うといくらなのだ？
つむぎ: 128GBの相場は10万4,280円。中古の16eは、電池90%以上の在庫がほとんどだよ。
つむぎ: 今日は体験の話に加えて、16や15、新品の17eと何が違って、どれを選ぶといいかまで話すね。

## 0:40 運営者の16e：1年半のメイン機

【画面】札: iPhone 16e 128GB ブラック / 2025年4月〜2026年10月 / 充電の上限 80%。小さく: 記事「iPhone 16eを半年使って分かったこと」（gadelog.com）

つむぎ: 使ったのは128GBのブラック。2025年の4月に買って、2026年の10月まで、毎日メインで使っていたよ。
ずんだもん: 決め手は何だったのだ？
つむぎ: 軽さと、電池の持ちと、デザインの3つ。
つむぎ: 16eはチップがA18で、16と同じ。画面は6.1インチ、端子はUSB-C。ここはAppleの技術仕様の値ね。

## 1:20 16eと16、何が違う？

【画面】表（iPhone 16e と iPhone 16・Apple の技術仕様）: チップ A18 / A18 ・ 背面カメラ 48MP の1つ / 48MP＋超広角 12MP ・ MagSafe なし / あり（最大25W） ・ カメラコントロール なし / あり ・ ビデオ再生 最大26時間 / 最大22時間 ・ 重さ 167g / 170g（列: ・16e・16）

ずんだもん: 16eと16は、チップが同じなら何が違うのだ？
つむぎ: いちばん大きいのはカメラ。16は後ろに2つあって、広く撮れる超広角がある。16eは4,800万画素のカメラが1つだけ。
つむぎ: それと、16は磁石でくっつくMagSafeに対応していて、ワイヤレス充電は最大25W。16eはMagSafeが無くて、置くだけの充電だけ。
つむぎ: 16には、写真を撮るためのカメラコントロールのボタンもあるけど、16eには無いよ。
ずんだもん: 16eのほうが、いいところはないのだ？
つむぎ: Appleの仕様だと、ビデオ再生は16eが最大26時間、16が22時間。重さも16eのほうが3g軽いの。
つむぎ: だから、景色を広く撮りたい人やMagSafeの道具を使う人は16。写真は1つのカメラで足りて、電池の持ちを重く見る人は16e、という分かれ方だよ。

## 2:30 よかった3つ

【画面】3つの札: 軽い / 電池が持つ（上限80%でも1日） / カメラの出っ張りが小さい（ケースで平ら）

つむぎ: 1つ目は軽さ。ズボンのポケットに入れても収まりがいいって。
つむぎ: 2つ目は電池。充電の上限を80%にしていても、1日は余裕。軽い使い方の日は2日目まで持ったそう。
ずんだもん: 仕様のビデオ再生が長いのと、合っているのだ。
つむぎ: 3つ目はカメラの出っ張り。カメラが1つだから出っ張りが小さくて、ケースを付けると机に平らに置けるの。
ずんだもん: 置いたときにガタガタしないのは、地味にうれしいのだ。
つむぎ: カメラが1つなのは弱点に見えるけど、運営者にとっては、ここがよかった点になっていたんだね。

## 3:30 割り切った点と、ひとつの不満

【画面】表: 超広角カメラ なし → 困らなかった / MagSafe なし → 対応ケースで / 映像出力 なし → 使わなかった / 指紋認証 なし（Face ID だけ） → 不満

ずんだもん: 削られた機能で、困ったことはないのだ？
つむぎ: 超広角のカメラは無いけど、1年半で困らなかった。足りなければ、下がって撮る。
つむぎ: MagSafeも無いけど、置くだけの充電はできるし、磁石が要るならケースで足せる。
ずんだもん: 不満は無かったのだ？
つむぎ: ひとつだけ。顔で開くFace IDだけで、指紋が無いこと。マスクのときは開きにくかったって。Apple Watchがあると楽になるそう。
つむぎ: ここは16も17eも同じで、どちらもFace IDだけ。指紋で開きたい人は、16eに限らず気をつけるところだよ。

## 4:30 1年半で電池は93%

【画面】大きな数字: 電池の最大容量 93%（充放電 304回・充電の上限 80%）

ずんだもん: 1年半で、電池はどのくらい減ったのだ？
つむぎ: 売る前に見たら、最大容量は93%。充電した回数は304回。
つむぎ: ずっと充電の上限を80%にしていたのも、効いているかもしれないね。
ずんだもん: 1年半で7%なのだ。
つむぎ: 中古で買うときも、設定の「バッテリー」で最大容量を見られる。お店の説明に数字が書いてあるかを、まず見てね。

## 5:10 売ったらいくら？下取りと買取店で1万5,400円

【画面】横棒（運営者の 16e 128GB・2026/10/24 の店頭査定）: 買取店A（ランクB・ケースの跡） 68,400円 / 買取店B 65,000円前後 / 買取店C 64,000円前後 / Apple の下取り（9/18 の見積もり） 53,000円 / 買取店D（修理歴で故障品の扱い） 14,000円。注記: 店の名前は出さない・記事Bの実測

ずんだもん: 売ったら、いくらだったのだ？
つむぎ: Appleの下取りの見積もりは5万3,000円。買取店に持っていったら、いちばん高い店で6万8,400円。
ずんだもん: 1万5,400円も違うのだ！
つむぎ: でも、1つの店では1万4,000円まで下がったの。バイクから落として、カメラのカバーガラスだけ、Apple以外のお店で直していたから。
ずんだもん: 直した跡で、5万円以上違うのだ…。
つむぎ: 修理歴の扱いは、お店ごとに違う。売るときは何店か聞いてみてね。
つむぎ: 今の買取の表示だと、16eの128GBの美品で6万6,150円。良品で6万円。
つむぎ: キズがあると5万2,500円まで下がる表示もあるの。美品との差は1万3,650円。
ずんだもん: ケースとフィルムで、売るときの値段も守れるのだ。
つむぎ: こういう、実際に使って売った数字も出していくから、よかったらチャンネル登録してね。

## 6:20 中古の16eの相場：10万4,280円

【画面】横棒（容量ごとの相場）: 128GB 104,280円 460件 / 256GB 115,269円 65件。下に: 電池の数字が分かる 128GB 286件のうち 90%以上 270件（94%）。注記: 大手中古ショップ16店・2026/11/17時点

ずんだもん: 今、中古で買うなら？
つむぎ: 128GBの相場は10万4,280円。460件ある。256GBは65件で11万5,269円。
つむぎ: 電池の数字が分かる128GBの在庫は286件で、そのうち270件が90%以上。
ずんだもん: ほとんど90%以上なのだ。
つむぎ: 発売からまだ新しい機種だからね。1年半で93%だった運営者の16eと、だいたい同じくらい。
ずんだもん: 電池がいいほうは、高いのだ？
つむぎ: 90%以上の真ん中は10万3,980円、80%から84%は10万2,800円。差は1,180円だけ。
つむぎ: 数が多いうえに値段もほとんど変わらないから、16eは90%以上の1台から選べばいいよ。

## 6:50 128GBと256GB、どっちにする？

【画面】表（容量と値段）: 中古の 16e 128GB 104,280円 / 中古の 16e 256GB 115,269円（+10,989円・65件） / 新品の 17e 256GB 124,800円（中古の 16e 256GB より +9,531円）（列: ・値段・差）。注記: 中古は同じ容量の中央値（2026/11/17）

ずんだもん: 容量は、128GBで足りるのだ？
つむぎ: 運営者は128GBで1年半使っていたよ。
つむぎ: 256GBにすると、中古で11万5,269円。128GBより1万989円高くて、在庫も65件と少ないの。
つむぎ: しかも、新品の17eの256GBとの差は9,531円まで縮む。
ずんだもん: 256GBがほしいなら、新品の17eも近いのだ。
つむぎ: そう。容量が多いほうがいい人は、16eの256GBより先に、新品の17eを見てね。

## 7:30 中古の15とどっちにする？

【画面】表（中古の相場・128GB・Apple の技術仕様）: 15 91,700円 A16 USB-C Face ID / 16e 104,280円 A18 USB-C Face ID（+12,580円）（列: 機種・相場・チップ・端子・認証）。注記: どちらも 6.1インチ・iOS 27 対応

ずんだもん: もう少し安くしたいなら、15なのだ？
つむぎ: 中古の15は128GBで9万1,700円。16eより1万2,580円低いの。
つむぎ: 画面はどちらも6.1インチで、端子もどちらもUSB-C。違うのはチップで、15はA16、16eはA18。
ずんだもん: チップが2世代違うと、何が変わるのだ？
つむぎ: チップは16eのほうが新しいA18。それと、Apple Intelligenceが使えるのはA18の16eのほう。15の無印のA16は対象外だよ。
つむぎ: 文字入力の手伝いや写真の整理みたいなAppleの新しい機能を使いたいなら16e。値段を優先するなら15、という選び方ね。

## 8:20 新品の17eとの差は2万520円

【画面】表: 中古の 16e 128GB 104,280円 A18 / 新品の 17e 256GB 124,800円（Apple） A19・容量2倍・MagSafe（+20,520円） / 中古の 16 128GB 116,700円 A18（+12,420円） / 中古の 17e 256GB 125,980円（新品より +1,180円）

ずんだもん: 新品と比べると、どうなのだ？
つむぎ: 後継の17eは、新品の256GBで12万4,800円。中古の16eの128GBとの差は2万520円。
つむぎ: 17eはチップがA19、容量はいちばん小さくても256GBで、16eの倍。それに、16eに無かったMagSafeに対応して、最大15Wで充電できるの。
ずんだもん: 2万円で、新しいチップと倍の容量と、MagSafeなのだ。
つむぎ: そう。写真や動画をたくさん残す人は、容量の差が効いてくる。しかも中古の17eは12万5,980円で、新品より高いの。17eにするなら新品を見てね。
つむぎ: 同じA18の16なら、中古の128GBで11万6,700円。16eより1万2,420円高い。超広角とMagSafeに1万2,420円を払うか、だよ。

## 9:10 修理代も16eは安い

【画面】表（Apple の修理料金・保証対象外・税込）: 16e 画面 41,800円 電池 17,200円 / 16 画面 45,800円 電池 17,200円 / 15 画面 45,800円 電池 17,200円（列: 機種・画面・電池）。注記: Apple の料金（10/21 確認）

ずんだもん: 壊したときの修理代は、違うのだ？
つむぎ: Appleで画面を直すと、16eは4万1,800円。16と15は4万5,800円で、16eのほうが4,000円安いの。
つむぎ: 電池の交換は、3つとも1万7,200円で同じ。
ずんだもん: 運営者みたいに落とすこともあるから、修理代は大事なのだ。
つむぎ: そう。それにApple以外で直すと、売るときに大きく下がることもあった。直すならAppleか、正規のお店がおすすめだよ。

## 9:40 SEからの乗り換えなら

【画面】表（Apple の技術仕様）: SE（第3世代） 4.7インチ・Touch ID・Lightning・A15・中古128GB 40,500円 / 16e 6.1インチ・Face ID・USB-C・A18・中古128GB 104,280円（+63,780円）

ずんだもん: SEから乗り換える人は、どうなのだ？
つむぎ: SEの第3世代の128GBは、中古で4万500円。16eとは6万3,780円の差。
つむぎ: 画面は4.7インチから6.1インチ。端子はLightningからUSB-Cになるから、充電のケーブルも替わるよ。
つむぎ: それと、指で開くTouch IDから、顔で開くFace IDに変わる。
つむぎ: 運営者の不満がFace IDだったから、指紋が好きな人は、ここだけは気をつけてね。
