# 横動画（longform/）

横動画の決まりはこのファイルだけに置く（スキル `longform-video` は手順、サムネはスキル `youtube-thumbnail`、ネタはスキル `video-ideas`）。
台本（`<フォルダ>/script.md`・つむぎとずんだもんの掛け合い）と数字（`<フォルダ>/data.json`）から 1920x1080 の動画を作る。作り方はショートと同じ（React の1コマ → `ImageResponse` で PNG → ffmpeg）。色は `lib/brandColors.ts` だけ。

**題を決める前に `docs/videos.md`（これまでの動画の一覧と数字）を読む。**

# 1. 今の決まり（11/23〜）

## 台本と画面の決まり

- **8分以上**。数字を読むだけにしない。**声に出す数字は1章1〜2個**、ほかは画面（横棒・表）。声は「なぜそうなるか」「どう選ぶか」「誰に向くか」
- **機能の紹介を入れる**: 比べる機種で何ができるようになるか（カメラ・端子・画面・チップ・電池の持ち・Apple Intelligence など）を、使う場面（写真・充電ケーブル・ゲーム）で言う
- 値は**公式で確かめたものだけ**（Apple の技術仕様・修理料金・新品価格・iOS の対応＝各版の iPhone ユーザガイド・lib/iphoneSpecs.ts ほか）。仕様で確かめられない機能は台詞に入れない。仕様にない機能を言うときは「ない」「ついていない」（「仕様に載っていない」は使わない・11/23）
- 構成の型: ①ずんだもんの困りごと（最初の15秒）②今日の◯つの道（地図）③機能の紹介 ④決め方 ⑤ずんだもんが決める（決着）⑥終了画面
- 「まだ使う？」シリーズ: 持っている人向け。電池交換・売って買い替え・新しい機種で増える機能の3つを、機能の紹介を中心に。個別の回を先に、まとめ版は後で。比べる相手は**今の機種とチップが同じ機種を外し**、足すお金が約5万円の機種を中心に（名機は「もう少し出せるなら」で最後に）
- 数字は data.json だけに書く（台本の数字を写す）。**公開の前日に取り直し**、台詞・data.json・説明欄を直す

### 冒頭の1分（11/22。視聴維持の API で決めた）

横動画は**最初の1分前後（10%）で半分が離れる**（ideas/2026-11-22-youtube-growth.md）。

- 最初の困りごとのあと、タイトルの問いへの答えを短く言う。**「結論から」とは言わない**。短くするより会話が自然なことを優先（11/24 ユーザー。冒頭をどこまで詰めるかは 12/1 の台本で最終判断。13 の回は最初の20秒で約3割が離れた）。**答えを全部は言わない**（16 の回は全部言って1分で36%、13 の回は「ここが今日のいちばん大事な話」と残して62%）
- 本編の「意外な数字」を1つ引っかかりとして先に出し、最後に「この先で分かること」を1行
- 冒頭でチャンネル登録を頼まない（いちばん強い発見の章の終わりで）。途中の1回は残してよい（11/24 ユーザー。13 の回の 5:19 の落ち込みは、目で読んだ1本だけではっきりしないため）
- 画面は台詞に合わせて数字が1つずつ出る（10秒前後ごとに変わる）

## 配置 d2（既定）

- 立ち絵は字幕の左右（画面の下の角・バストアップで顔を大きく・カードの上に描く）。名札は立ち絵に重ねず上に出し、フェードで消す
- 字幕の帯は x212〜1708・62px（袋文字・話し手の色の縁）。2行まで、長い台詞はページに分ける。帯の下は再生バーの分あける
- カードは左右いっぱい 1888x782（余白 16px）・文字の上限 1.3 倍。章の題は上寄せ。本文の文字はなるべく大きく
- **脚注（note）は画面に出さない**（出典は説明欄。画像の出典だけ画面に出す）
- 文字の最小: 本文 34px（scenes.tsx の `MIN_FONT`）。収まらないときは縮めず data.json を短くする（`render.ts stills`・`video.tsx` は届かない所を出して止まる）
- 丸数字は数字が円の真ん中に来るか拡大して見る

## 動き

- 項目が出る・字幕が替わる・話し始めに、少し下から浮き上がって止まる（ease-out 約0.27秒・項目 6px・字幕 3px・立ち絵 6px。scenes.tsx の animAt）。控えめに
- 項目は**台詞が触れ始めたときに出す**（cue の台詞の中で、ラベルの先頭の語か `say` を言う位置）。先に出ている項目に台詞が触れたら、その瞬間だけ小さく震える（timeline.ts の resolveMentions）。位置がずれていないか見る
- 横棒は左から約0.6秒で伸び、値も 0 から数え上がる。同じ秒の棒は 0.2 秒ずつずれる。**スライドが替わった瞬間に伸び切った棒が見えないこと**
- 字幕の残り時間: 話し手の色の線が帯の上辺を左から右へ等速で伸びる
- 口と立ち絵は声の波形で揺らす（0.1秒ごと・1段 2px）。動く所は 30fps
- **リップシンク（12/1 の回〜）**: 口は VOICEVOX のモーラの時刻から母音（あいうえお）の形に。ん・っ・間は閉じる（shorts/voice.ts の visemesOf・口の絵は chara-video-expr.py）
- **表情（12/1 の回〜）**: 台詞の言葉で表情を替える（ずんだもん「！」「え、」で驚き・困る言葉で青ざめ／つむぎ「！」で驚き・勧める言葉でウインク。scenes.tsx の lineExpr）。表情の台詞は口が開く・閉じるの2つ
- **✓・×（12/1 の回〜）**: 表の「○」「×」は緑の ✓・赤の × の丸に（行が出た瞬間に少し大きく）。チェックリストは説明した順に**上から**緑の ✓（説明の前の番号は灰色。赤の ✓ は日本では「まちがい」に見える）。✓ を付ける台詞は自動（項目に触れた最初の台詞）か checkCue
- **効果音（12/1 の回〜）**: 項目が出る・写真が替わる・✓ が付く＝pop、揺れる＝shake1（ちょこっと触る）、蛍光ペン＝mark1（カーソル移動2）。動きごとに1種類（効果音ラボ。蛍光ペンを揺れより優先）。0.7 秒以内に続く音・章のジングルの前後は鳴らさない（video.tsx の seEvents。LONGFORM_SE=0 で止める）
- **蛍光ペン（12/1 の回〜）**: 台詞の頭（10字以内）で項目に触れた台詞の間、その行に薄い黄色（timeline.ts の resolveMarks）
- **表の数え上げ（12/1 の回〜）**: 表の金額も横棒と同じく 0 から数え上がる（頭の数字だけ）
- **章の切り替え（12/1 の回〜）**: カードが右から 90px 寄ってくる（10コマ・ease-out）
- **図解の場面（12/1 の回〜・11/27 ユーザー OK）**: 困りごとのカード（problems）・2年の総額の積み上げ棒（costs）・分かれ道（flow）・2択のカード（versus）・並べる（lineup）・はんこ（stamp）・線グラフ（trend）・年表（years）・写真の図解（notes・＜ーー＞）・電池のゲージ（gauges）・設定画面の絵（screen）。見本は longform/fx-sample〜fx-sample5。積み上げ棒は横棒（rows）、並べるは頭に帯のカード（tab）＋丸はんこが既定（11/27 ユーザー）
- カメラの寄り・差の札・値のポップ・集中線・思考の吹き出し（think）・出典カード（source）は試して使わないことにした（11/27 ユーザー「微妙」「いらない」）
- 2章目からは章の頭に短いジングル

## 画像・拡大

- 画像はたくさん。部品 `photo`（画像＋右に機能の行）で、話が変わるたびに `images` で差し替える。`credit` は画像の下と説明欄（「画像：」）に出る
- 素材: CC の写真（Wikimedia Commons など。作者・ライセンス・URL。素材は `longform/assets/commons/`）・いらすとや（1作品20点まで）・自分のスクショ（設定画面など）
- **公式の画像（Apple・Google・Samsung の製品画像・スクショ）は引用として使う**: 説明が主で画像は従（その章に要る画像だけ・画面の一部）、credit に「出典：Apple（ページの URL）」。画像に手を加えない（切り抜きは可・文字や絵を重ねない）
- 生成画像（ComfyUI・`C:\Users\GT\Desktop\git\comfyui-rocm10`・RealVisXL）は**いまは使わない版が既定**。使うときは機種を特定しないイメージだけ・スマホの画面とロゴを写さない・AI の注釈は画面に出さず説明欄に・本物に見えるなら Studio の「改変または合成されたコンテンツ」をオン。保存は `longform/assets/ai/`
- 拡大は `crop: { x, y, w, h }`（割合）で、**その話をするときだけ**（最初の1枚は拡大しない）。端末の写真は上下の余白を削って大きく
- グラフの単位: 万円・円・件・機種・年・時間・g。札の文字は `pickLabel`（なければ「おすすめ」）

## 年の目安と言わないこと

- 「あと何年使えるか」は「Apple は新しい iOS を何年出すか約束していない。これまでの記録から数えた見込み」と**声と画面で断ったうえで**言ってよい（案B）
- 言わないこと: 値動きの予想・店の良し悪し・「最安」「必ず」「絶対」「お得」・公式で確かめていない機能

# 2. 仕組みとコマンド

## コマンド

```
python -I longform/chara.py                         # 立ち絵（assets/src の PSD → assets/chara の PNG）
npx tsx longform/voice-draft.ts <dir>               # 声（voice-draft.m4a・chapters.txt）。VOICEVOX が要る
npx tsx longform/timeline.ts    <dir>               # 時間割 timeline.json（声の長さはキャッシュから）
npx tsx longform/render.ts      <dir> stills        # 章ごとの見本 stills/ch*.png と一覧 stills/contact.png
npx tsx longform/render.ts      <dir> frame 95.5    # その秒の1枚（--open で口を開けた絵）
npx tsx longform/video.tsx      <dir> plan          # 区切りの数・PNG の枚数・見積もりだけ
npx tsx longform/video.tsx      <dir>               # 動画全体（video.mp4・chapters.txt・youtube.txt・endscreen.txt・thumbnail.png）
npx tsx longform/video.tsx      <dir> check         # 長さ・音量・同期3か所・見本（stills/check-*.png）
```

- 書き出す順: **voice-draft.ts（今の辞書で合成し直す）→ timeline.ts → video.tsx**。古い声（stale）や見積もりの行が残っていると video.tsx は止まる。段だけやり直すときは `frames` / `encode` / `audio` / `mux` / `meta`
- `timeline.json`・`frames/`・`video.mp4`・`stills/check-*.png`・`longform/assets/` は Git に入れない。`stills/`・chapters.txt・youtube.txt は残す

## 書き出しの速さ

- video.tsx は絵を4つの層に分ける（11/24〜）: **土台**（1920x1080。章・字幕のページ・項目・揺れ・棒が伸びる間だけ PNG）と、毎コマ動く**話している人の立ち絵**（声で揺れる・口）と**字幕の縁の線**（残り時間）の小さな PNG（数百枚・透明）。ffmpeg が concat の一覧（層ごと）を 30fps にそろえ、毎コマ overlay で重ねて H.264 にする。17e の回（8:29）で PNG 14,150 枚 → 土台 1,683＋小さな絵 751 枚、PNG 298 秒 → 32 秒・映像 74〜124 秒 → 36〜47 秒・全体 約1.7分（何も使い回さないとき）
- concat の一覧には `option framerate 30` を入れる（入れないと PNG の時間の単位が 1/25 秒になり、切り替えが 1/25 秒に丸められて 6コマに1コマ落ちていた。11/24 までの動画はそうなっていた）
- PNG は22本並べて作り（`LONGFORM_JOBS`）、絵の指紋が同じ PNG は前の書き出しのものを使い回す（直しが1か所なら数秒）。ffmpeg は論理コア数−2 スレッド（`LONGFORM_FF_THREADS`）・preset superfast（11/24〜）。GPU（`LONGFORM_GPU=1`）は CPU より遅かった（11/24: 49 秒 対 36〜42 秒）
- 動く所はすべて毎コマ（30fps）で描く。**15Hz にしない**（11/24 ユーザー。`LONGFORM_MOTION_HZ` は試し用）
- 見せるときは 720p の確認用（30MB 超はスマホに届かない）

- 音は声（joined.wav）・BGM・ジングル・長さが前と同じなら前の audio.m4a を使い回す（frames/audio-<指紋>.m4a・11/24）。映像は preset ultrafast（11/24〜・ファイルは約2倍の 70MB だがどうせ手でアップロードする）。17e の回で 1.7分→1.0分、声が同じ直しなら 0.6分
- 切り抜きショート: `npx tsx longform/clip-short.tsx <フォルダ> <開始-終了,…> "<題1>" "<題2>" <名前>`（会話のラリーを3〜5つつなぐ・53秒まで。関連動画に元の横動画）
## 音

声（voice-draft/joined.wav）を -16 LUFS → BGM（shorts/assets/bgm.mp3）をくり返して 0.07 倍・頭2秒で上げ最後4秒で下げる → loudnorm 2パスで -14 LUFS・真のピーク -1。最後の台詞のあと 1.5 秒（終了画面があれば 20 秒まで BGM）。章の頭のジングルは video.tsx の makeJingle がその場で合成（E5→G#5→B5・0.75秒・-18 dBFS）。

## 説明文の下書き（youtube.txt）

video.tsx の meta が作る。タイトルは script.md「タイトル案」の 1.、本文は「概要欄（下書き）」（チャプターは実測で差し込む）、utm_campaign は フォルダ名の日付（`long_YYYYMMDD`）、クレジットは VOICEVOX の2人・BGM・効果音・立ち絵・photo の credit（「画像：」）。公開前に上の「説明欄の形」に直す。

## 部品（data.json の scene）

| type | 中身 |
| --- | --- |
| `bigNumber` | 大きな数字・言葉（2〜3個）。値・単位・ラベルの大きさは全項目でそろえる |
| `bars` | 横棒＋最安の赤い点・在庫数・札（`pickLabel`）。単位は上の「画像・拡大」。ラベル＋補足（2行）なら5行まで |
| `pairs` | 2本ずつの棒と差（色は SITE のキー） |
| `table` | 表（emphasis の列を赤く）。各列のいちばん長い文字の合計が 2列 約33em・3列 約32em・5列 約29em まで |
| `checklist` | 番号つきの行を1つずつ出す |
| `photo` | 画像＋機能の行。`credit`・`images: [{ src, credit, cue }]`（差し替え）・`crop` |
| `endScreen` | 終了画面（最後の章だけ） |

- 各項目の `cue` は「この文字列を含む台詞が始まったら出す」。見つからなければ timeline.ts が警告して最初から出す

## 声と読み

- `script.ts` が script.md を章・【画面】・台詞に分ける（行の間 0.25 秒・章の間 1.1 秒・速さ 1.15）
- 読み違いは `shorts/voice.ts` の READING_FIXES か `longform/script.ts` の forVoice（十分→じゅうぶん・6s→ロクエス・MP→メガピクセル・電池の値→あたい・「今のうちに」は切らない）。声を作ったらキャッシュの `spoken`・`kana` で確かめる
- キャッシュ: timeline.ts は `shorts/voice.ts` の `synthesize` で長さを読む。鍵に辞書（`shorts/voice-dict.json`）が入るため、辞書を足すと当たらず、古いキャッシュで長さだけ測る（`stale: true`）。書き出す前に voice-draft.ts で合成し直す

## チャンネル登録の重ね
