# TikTok の運用（@used_gadelog）

YouTube ショート（`.claude/skills/youtube-shorts/SKILL.md`）で作った動画を、**BGM なしで書き出し直して**、TikTok Studio（PC）から1本ずつ手で上げる。
調べた経緯と出典は `ideas/2026-10-26-tiktok.md`。記録は `ideas/YYYY-MM-DD.md`。報告は日本語。

## 守ること（変えない）

- **自動化しない**。TikTok は投稿の自動化ツール・スクリプトを禁止している（コミュニティガイドライン 2026/9/24 発効）。
  - 投稿は、ユーザーの Chrome の TikTok Studio で、YouTube Studio と同じく **1本ずつ画面を操作して** 行う。まとめて上げる・投稿や予約のスクリプトを書く・API で上げる、はしない。
  - 予約を使うなら TikTok Studio の標準の予約だけ（1本ずつ）。
- **曲**: YouTube オーディオライブラリの曲（`shorts/assets/bgm.mp3`）は使わない。必ず BGM なし版（`short-A-nobgm.mp4`）を上げる。
  - 曲を付けるなら、ユーザーが TikTok の中で商用ライブラリ（CML）の曲を選ぶ（Claude は選ばない）。
- **オリジナルの書き出しを上げる**。YouTube から保存した透かし入りの動画は使わない。
- **同じ動画を2回上げない**（上げ直しはしない。直したい点は公開前に直す）。同じテーマ・同じデータの回を同じ日に2本出さない。
- **投稿の削除はしない**（禁止。崩れたらユーザーに頼む）。下書きを捨てるのは可。
- **キャプションは打鍵で入れる**。文字を JS（`execCommand('insertText')`・value の書き換えなど）で入れない（X で 10/19 に文が二重になった）。入力は `computer` の type だけ。打鍵の前に `document.visibilityState === 'visible'` を確かめる（hidden なら Chrome を前に出す。手順は `.claude/skills/x-ops/SKILL.md` の「Chrome の準備」）。
- **広告（PR・アフィリエイト）の回は、フォロワー1,000人までは出さない**（リンクも置けない）。出すときは:
  - 投稿の設定の「コンテンツの開示」→「商用コンテンツ」（ブランドコンテンツ）を **オン**。
  - 動画の中（声と左上の「PR」）とキャプションの先頭の「#PR」で広告と分かるようにする（楽天の指針: 概要欄だけは不可・「AD」は不可）。
  - 金融（保険・カード・ローン）の案件は TikTok では扱わない（招待制）。青山龍星の声の回は PR にしない（企業が関わる形は事前確認が要る）。
- **AI ラベル**: 文字と図形＋合成音声（VOICEVOX）の動画は「本物のように見える場面や人物を AI で作った」に当たらないと読めるので、いまはオンにしない。実写風の画像や人物を AI で作った回を出すときはオンにする。TikTok が自動でラベルを付けたら外さない。
- **リンク**: プロフィールのリンクはフォロワー1,000人から。それまではキャプションに「相場は used.gadelog.com で検索」と文字で書くだけ（utm は付けない・押せない）。動画の締めの「プロフィールのリンクから」は、プロフィールの文の used.gadelog.com を指す。
- **クレジット**: キャプションの末尾とプロフィールに「VOICEVOX:<キャラクター名>」。BGM のクレジットは入れない（BGM なし版のため）。

## 1回分の手順

1. **選ぶ**: `shorts/out/` のうち、YouTube に出した回で、TikTok にまだ上げていないもの（記録 `ideas/` を grep して確かめる）。最初の2週間は値下がり（drops）・機種の差額（provs・promax・plusvs など）・予算別を回す。PR の回（rakutenmobile）は選ばない。
2. **BGM なしで書き出す**: `npx tsx shorts/make-short.tsx <テーマ> render --no-bgm --dir shorts/out/<日付>-<テーマ>` → `short-A-nobgm.mp4` と `youtube-nobgm.txt`。
   - 重い処理なので、ほかの render と同時に走らせない（この PC は負荷で落ちる）。すでに `short-A-nobgm.mp4` があれば作り直さない。
   - 長さ・声の大きさを確かめる（BGM 入りの版と同じ決め方）。
3. **キャプション**: `npx tsx shorts/tiktok-caption.ts shorts/out/<日付>-<テーマ>` → `tiktok.txt`（全文と字数が出る）。
   - 中身: つかみ（タイトル）→ 数字（4行まで）→ データの出どころ → 「相場は used.gadelog.com で検索」→ VOICEVOX のクレジット → ハッシュタグ3〜4個（#中古iPhone #iPhone #中古スマホ ＋ テーマの1個）。
   - 上限 2,200 字。フィードで見えるのは最初の100字ほど → つかみと1行目の数字をそこに入れる。
   - 広告の回はコンソールに「商用コンテンツをオン」の注意が出る（キャプションには書かない）。
4. **ファイル名を変えてコピー**: アップロードの前に `short-A-nobgm.mp4` を他と重ならない名前にコピーする（例 `tiktok-20261026-bigbudget.mp4`。同じ名前のファイルを続けて入れると取り違える）。
5. **ユーザーに確かめる**: 上げる動画・キャプション全文・公開の時刻を見せて OK をもらう。**投稿はユーザーの OK のあと**（1本ごと）。
6. **投稿**（ユーザーの Chrome・TikTok Studio。下の「TikTok Studio の手順」）
   - アップロードのページでファイル入力に `file_upload` でコピーした mp4 を入れる。
   - キャプションの欄をクリック → 打鍵で `tiktok.txt` の全文。ハッシュタグの候補が開いたら、候補を選ばずに入力を続ける。
   - カバー: つかみ（最初の画面）か1位の発表の画面。
   - 設定: 公開範囲「すべての人」・コメント可。広告の回だけ「商用コンテンツ」をオン。AI ラベルは上の決まりのとおり。
   - 投稿 → 公開された動画の URL（tiktok.com/@used_gadelog/video/<ID>）を控える。
7. **記録とコミット**（下の「記録」）。

## 投稿の時刻と本数

- **最初の2週間（10/26〜11/8）: 1日2本・19〜21時ごろ**。2本は2時間ほどあけ、テーマを変える。
- 2週目からは TikTok Studio の「フォロワーのアクティビティ」で、多い時間に寄せる。
- 3週目から、1分を超える版を週2本試す（Creator Rewards は1分超のオリジナルが対象。いまの30〜45秒は対象外）。

## 見る数字（TikTok Studio の分析）

- 1本ごと（公開48時間後）: 再生数・**おすすめ（For You）からの割合**・平均視聴時間・**完全視聴率**・フォロー数・プロフィールの閲覧。
- アカウント: フォロワー数・プロフィールの閲覧。
- **4週目（11/23 ごろ）の判断**: 1本の再生の中央値 **500 以上** か フォロワー **300 以上** → 続ける。どちらも届かなければ1日1本に減らす。
- フォロワー1,000人になったら（ユーザーがする）: プロフィールのリンク・VC・A8・楽天への TikTok アカウントの登録。それまで PR の回とアフィリエイトのリンクは出さない。

## 記録

- `ideas/YYYY-MM-DD.md` に追記する: 動画の URL・テーマ・元の YouTube の回（`shorts/out/<フォルダ>`）・公開の時刻・長さ・キャプションの1行目・設定（商用コンテンツ・AI ラベル）・48時間後の数字。
- 運用を変えたら、このスキルと STATE.md（決定事項・確認台帳）を同じターンで直す。
- コミットはするが push はユーザーの指示があるとき。

## TikTok Studio の手順（10/26 の1本目で確かめた）

- アップロード: `https://www.tiktok.com/tiktokstudio/upload` → `find` で「input type=file」→ `file_upload`。上がると説明の欄にファイル名が入る
- 初回だけ「コンテンツの自動チェックをオンにしますか？」（アカウントの設定）と「新しい編集機能」の案内が出る → 自動チェックはオンにせず閉じる（キャンセル）・案内は OK
- 説明の欄は `[contenteditable=true]`（1つだけ）。scrollIntoView → 座標でクリック → ctrl+a → Delete でファイル名を消す → activeElement を確かめてから type。改行は type の「
」でそのまま入る。ハッシュタグの候補が開いても、続けて打てば候補は選ばれない（最後に空白を打つ）。上限 4,000 字（表示 366/4000）
- カバーは最初の画面が自動で入る（変えるなら「カバーを編集」）
- 設定: 「さらに表示」を開くと コメント・コンテンツの再利用・リミックス（既定オン）・「投稿コンテンツを開示」（商用コンテンツ・既定オフ）・「AI生成コンテンツ」（既定オフ）。投稿のタイミング「今／投稿予約する」・公開範囲「誰でも」
- チェック: 「コンテンツの簡易チェック」をオン（約10分 → 「違反は見つかりませんでした」）。音楽の著作権チェックは BGM なしなので不要
- 投稿のボタンは `data-e2e="post_video_button"`（左の「投稿」メニューと同じ文字なので、find や文字で探すと取り違える）。画面の高さが変わるので、押す直前のスクショの座標で押す
- 押すと `tiktokstudio/content` に移り「動画が公開されました」。動画の URL はプロフィール（`/@used_gadelog`）の `a[href*="/video/"]`
