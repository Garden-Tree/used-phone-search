# 動画のネタ出し

報告は日本語・短く。ブラウザはサブエージェント（Chrome の専用プロファイル「used」＝list_connected_browsers の Browser 1 を select_browser）、分析とネタは自分。

## 守ること

- **他人の題・構成・サムネを写さない**。取るのは型だけ。中身はうちのデータと公式の値
- 言わないことは `longform/README.md`「言わないこと」
- YouTube では読むだけ（いいね・登録・コメントしない）
- 同じテーマで結論が同じ回は作らない（`docs/videos.md`）
- オリジナルのショートは作らない（切り抜きだけ）

## 手順

1. `docs/video-competitors.md` を読む（新しく調べたら直す）
2. `docs/videos.md` を読む（古ければ `npx tsx scripts/video-index.ts`）
3. うちの数字: `npx tsx scripts/yt-metrics.ts --days 40`。今の再生は Data API の viewCount。インプレッション・CTR・視聴を継続は Studio のアナリティクス（サブエージェント）
4. 競合: サブエージェントに下の表のチャンネルの人気順30・新しい順30（題・再生・日数・登録者）と、検索（「中古iPhone」「iPhone まだ使える」「iPhone 買い替え」「中古スマホ おすすめ」「スマホ おすすめ 2026」）の上位20を `.claude/tmp/yt-competitors-<MMDD>.md` に表で
5. 型に分ける: 持っている人／これから買う人／比べる／避ける（地雷）／ランキング・BEST／使い方。型ごとに再生の中央値÷登録者、新しい順30 の中央値の2倍以上を「当たり」として題の言葉を拾う
6. うちのデータ（相場・在庫・買取・電池・公式の仕様／修理料金）で答えが出ない型（開封・使用感・速報）は捨てる
7. 案を5〜10本: 型・題の案3つ・使うデータ・公式ページ・画像の候補・似た既存の回。横動画は週3〜4（残りの日は切り抜き）
8. 記録: `ideas/YYYY-MM-DD-video-ideas.md`。決めたことは STATE.md と docs/changes.md に同じターンで
