# 動画のネタ出し（11/23〜）

報告は日本語・短く。経緯と結果は `ideas/YYYY-MM-DD-video-ideas.md`。ブラウザの作業はサブエージェント（ユーザーの Chrome・1つずつ）、分析とネタは自分。

## 守ること

- **他人の題・構成・サムネを写さない**。取るのは「型」（誰に向けた問いか・どんな比べ方か・何を約束する題か）だけ。数字と中身はうちのデータ（相場・在庫・買取・電池・Apple などの公式の値）で作る
- 公式で確かめていない機能・値段は使わない。「あと◯年使える」・来年以降の OS の予想・値動きの予想・店の良し悪しは言わない。「最安」「必ず」「絶対」「お得」は使わない
- YouTube では読むだけ（いいね・登録・コメントしない）
- 同じテーマで1位や結論が同じ回は作らない（`docs/videos.md` で確かめる）

## 手順

1. **うちの一覧を読む**: `docs/videos.md`（古ければ `npx tsx scripts/video-index.ts`）。ショートは `.claude/skills/youtube-shorts/SKILL.md` の「11/23〜 の決まり」（続けるネタ・やめたネタ）、横動画は `longform/README.md`「台本と画面の決まり」
2. **うちの数字**: `npx tsx scripts/yt-metrics.ts --days 40`（1本ごとの再生・平均視聴・登録・流入元）。いま伸びている回は Data API の viewCount（Analytics は2〜3日遅れ）。インプレッション・CTR・視聴を継続は API にない → サブエージェントで Studio の アナリティクス → コンテンツ（動画／ショート・過去28日）と詳細モード（内訳＝コンテンツタイプ）
3. **伸びている人の動画**: サブエージェントに下の「見るチャンネル」の 人気順30・新しい順30（題・再生数・公開からの日数・登録者数）と、検索（「中古iPhone」「iPhone まだ使える」「iPhone 買い替え」「中古スマホ おすすめ」「iPhone レビュー」「スマホ おすすめ 2026」）の上位20を集めさせ、`.claude/tmp/yt-competitors-<MMDD>.md` に表で書かせる
4. **型に分ける**（自分）: 題を「誰に向けた問いか」で分類する
   - 持っている人（まだ使える？・いつまで・売る／直す）／これから買う人（今買い？・どれを買う・予算別）／比べる（A と B・新旧）／避ける（買うな・地雷）／ランキング・BEST／使い方・設定・小ワザ
   - 型ごとに 再生の中央値÷登録者数（登録者の何倍見られたか）を出す。新しい順30 の中央値をそのチャンネルの「ふつう」とし、その2倍以上の回を「当たり」として題の言葉を拾う（数字・言い切り・対象・期間）
5. **うちで作れるかの印**: 型ごとに、うちのデータで答えが出せるか（相場・在庫・買取・電池の分布・公式の仕様／修理料金）。出せない型（開封・実機の使用感・新製品の速報）は捨てる
6. **ネタの案**: 5〜10本。各案に「型・題の案（3つ）・使うデータ・機能の紹介に使う公式ページ・画像の候補（CC／公式の引用）・似た既存の回」。横動画を優先（週2本）。ショートは続けるネタだけ
7. **記録**: `ideas/YYYY-MM-DD-video-ideas.md` に、集めた表のまとめ・型ごとの数字・案。決めたことは STATE.md（次にやる）と docs/changes.md に同じターンで。見るチャンネルが変わったらこのスキルの表を直す
